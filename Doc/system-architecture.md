# สรุป System Architecture

## ภาพรวม
เอกสารนี้สรุปโครงสร้างทางสถาปัตยกรรมของโปรเจกต์เว็บไซต์พอร์ตโฟลิโอ

## วัตถุประสงค์ของโปรเจกต์
โปรเจกต์นี้เป็นเว็บไซต์พอร์ตโฟลิโอส่วนตัวที่พัฒนาโดยใช้ Next.js, TypeScript และสไตล์ที่คล้าย Tailwind CSS เพื่อแสดงข้อมูลเกี่ยวกับเจ้าของเว็บไซต์ เช่น ประวัติส่วนตัว ทักษะ โปรเจกต์ การศึกษา ข้อมูลติดต่อ และเรซูเม่

## โครงสร้างหลักของโปรเจกต์
- โครงสร้างแบบ App Router ภายใต้โฟลเดอร์ app/
- คอมโพเนนต์ UI ที่ใช้ซ้ำได้ภายใต้ app/components/
- Context สำหรับจัดการธีมภายใต้ app/context/
- ไฟล์สถิติและทรัพยากรต่าง ๆ ภายใต้ public/

## แนวคิดสำคัญของสถาปัตยกรรม
1. การแสดงผลแบบ client-side ด้วย Next.js
2. การจัดระเบียบ UI แบบ component-based
3. การจัดการธีมในจุดกลาง
4. การเก็บเนื้อหาและไฟล์ทรัพยากรแบบสถิต

## ส่วนเนื้อหาที่ควรมีในเว็บไซต์
- ส่วน Hero
- ส่วน About
- ส่วน Skills
- ส่วน Projects
- ส่วน Education
- ส่วน Contact
- ส่วน Footer และ Navbar

## หมายเหตุ
เอกสารนี้สามารถขยายต่อได้ในอนาคตด้วย
- แผนภาพสถาปัตยกรรม
- คำอธิบายการไหลของข้อมูล
- โครงสร้างการ deploy
- ข้อพิจารณาเรื่อง scalability
